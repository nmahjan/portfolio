FootballMind

Ouvrir l’application ↗ Voir le code source
DATE 2026 TYPE Analyse prédictive / IA

Une plateforme conversationnelle d’intelligence footballistique couvrant huit grandes compétitions. Posez une question sur un match en langage courant et obtenez des probabilités de victoire, de nul et de défaite fondées sur les données, ainsi que les buts attendus, la forme, l’historique des confrontations, les compositions prévues et, au choix, une analyse rédigée par l’IA.

Ce qui la distingue :

  • Moteur hybride Elo + Dixon–Coles réglé par rétrovérification progressive selon le Ranked Probability Score
  • Matchs en direct, classements, tableaux de tournoi, données sur les joueurs, onze titulaires prévus et calibration de la confiance
  • Relances conversationnelles tenant compte de la compétition et comparaisons de joueurs dans huit compétitions
  • Ingestion, enrichissement, réentraînement du modèle et évaluation les jours de match automatisés avec GitHub Actions
  • Une couche de services commune accessible depuis une application web React, une API REST et plus de 13 outils MCP

Réalisé avec :

Python React Vite Flask PostgreSQL Elo Dixon–Coles MCP

Résultat :

Livraison d’un système de production couvrant la modélisation statistique, l’ingénierie de données, les outils pour LLM et la conception frontend. Le modèle se réentraîne et évalue continuellement ses prévisions, afin que son niveau de confiance soit mesuré plutôt que simplement affirmé.

Comparatif d’IA — Analyseur de statistiques de basketball

Ouvrir l’application ↗ Voir le code source
DATE Avril 2026 TYPE Comparaison d’outils d’IA / Full-stack

Comparatif direct de six outils de programmation par IA — BMAD v4, Traycer, Amp, Superpowers, Ralph et BMAD v6 — chacun chargé de créer de zéro la même application Flask de statistiques de basketball. Évaluation de la qualité du code, de l’exactitude et de l’expérience développeur à l’aide d’une grille normalisée. Création d’un tableau de bord interactif permettant de comparer côte à côte le résultat en direct de chaque outil.

Fonctionnalités principales :

  • Six applications Flask développées indépendamment et exécutées sur des ports isolés (8080–8085)
  • Grille normalisée évaluant l’exactitude, la qualité du code et l’UX
  • Tableau de bord interactif avec sélecteur d’iframes pour une comparaison côte à côte
  • Pipeline automatisé de prérendu statique déployant toutes les applications sur GitHub Pages
  • Conception adaptative du sélecteur et de toutes les pages d’outils
  • Flux CI/CD avec GitHub Actions pour le déploiement continu

Technologies utilisées :

Python Flask pandas HTML/CSS JavaScript GitHub Pages GitHub Actions

Résultats :

Superpowers a obtenu la meilleure note (35/40), tandis que Traycer et Amp sont à égalité avec 32. BMAD v4 et BMAD v6 ont obtenu 30, tandis que Ralph n’a pas produit d’application fonctionnelle (8/40). Le sélecteur en direct permet d’explorer instantanément le résultat de chaque outil et offre un comparatif transparent et reproductible pour évaluer les flux de développement assistés par IA.

Analyse du risque de maladie cardiaque avec R

Voir le code source
DATE Automne 2024 TYPE Science des données et analyse statistique

Projet d’analyse statistique complet portant sur les facteurs de risque cardiovasculaire à partir du jeu de données UCI Heart Disease (1 025 dossiers de patients). Développement de modèles prédictifs pour identifier les patients à haut risque et analyse des principaux indicateurs cliniques associés au diagnostic de maladie cardiaque.

Fonctionnalités principales :

  • Pipeline complet de prétraitement et de nettoyage de 14 variables cliniques
  • Analyse exploratoire avec visualisations professionnelles dans ggplot2
  • Modèle de régression logistique atteignant 84,8 % de précision et une AUC de 0,93
  • Analyse de corrélation identifiant les principaux facteurs de risque (type de douleur thoracique, dépression ST, nombre de vaisseaux)
  • Tests de significativité statistique (tests t et du khi carré) des tendances démographiques
  • Rapport R Markdown complet avec analyse reproductible

Technologies utilisées :

R R Studio ggplot2 dplyr caret corrplot R Markdown

Résultats et enseignements :

L’analyse a montré une prévalence significativement plus élevée des maladies cardiaques chez les hommes que chez les femmes, ainsi qu’une forte association avec les douleurs thoraciques asymptomatiques. Le modèle prédictif a obtenu de solides performances (précision supérieure à 80 %, AUC de 0,93), démontrant son potentiel pour l’évaluation clinique des risques. L’analyse a révélé que la fréquence cardiaque maximale et la dépression ST sont des indicateurs diagnostiques essentiels. Le projet démontre ma maîtrise de la modélisation statistique, de la visualisation et de l’analyse de données médicales.

Schéma du flux du script Python

Script automatisé d’organisation des données

DATE Été 2024 TYPE Automatisation des processus — Projet de stage

Développement, pendant mon stage, d’un script Python intelligent qui a transformé les flux d’organisation des données. Le script extrait les noms depuis des emplacements précis, classe intelligemment les fichiers supplémentaires selon des critères de correspondance et organise l’ensemble de façon systématique, économisant environ deux semaines de travail manuel par cycle.

Fonctionnalités principales :

  • Extraction automatisée des noms depuis des arborescences désignées
  • Algorithme intelligent de correspondance pour identifier les fichiers liés
  • Analyse multifactorielle de similarité (noms, dates, métadonnées)
  • Traitement par lots de centaines de fichiers simultanément
  • Gestion complète des erreurs et système de journalisation
  • Contrôles de validation assurant un classement précis
  • Génération de rapports CSV pour la piste d’audit et la vérification

Technologies utilisées :

Python 3 pandas os/pathlib Expressions régulières Entrées-sorties de fichiers Gestion des erreurs

Impact sur l’entreprise :

Réduction du temps d’organisation des données de deux semaines à environ deux heures par cycle, soit un gain de temps de 98 %. Élimination des erreurs humaines de classement, faisant passer la précision d’environ 85 % à 99,5 %. Plus de 1 000 fichiers traités sans erreur lors du premier déploiement. Le script a été adopté comme flux standard par l’équipe et économise encore plus de 80 heures de travail manuel par mois. Mon responsable a salué cette résolution novatrice de problèmes et les gains d’efficacité mesurables. Le projet démontre ma capacité à repérer des possibilités d’automatisation et à livrer des solutions prêtes pour la production, créatrices de valeur.
