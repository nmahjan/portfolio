FootballMind

Ouvrir l’application ↗ Voir le code source
DATE 2026 TYPE Analyse prédictive / IA

Une plateforme d’analyse footballistique couvrant huit grandes compétitions. Les requêtes en langage naturel renvoient des probabilités calibrées de victoire, de nul et de défaite, ainsi que les buts attendus, la forme récente, l’historique des confrontations, les compositions prévues et une analyse facultative générée par l’IA.

Points techniques :

  • Moteur hybride Elo + Dixon–Coles réglé par rétrovérification progressive selon le Ranked Probability Score
  • Matchs en direct, classements, tableaux de tournoi, données sur les joueurs, onze titulaires prévus et calibration de la confiance
  • Relances conversationnelles tenant compte de la compétition et comparaisons de joueurs dans huit compétitions
  • Ingestion, enrichissement, réentraînement du modèle et évaluation les jours de match automatisés avec GitHub Actions
  • Une couche de services commune accessible depuis une application web React, une API REST et plus de 13 outils MCP

Réalisé avec :

Python React Vite Flask PostgreSQL Elo Dixon–Coles MCP

Résultat :

Construction d’un système de bout en bout combinant modélisation statistique, pipelines de données automatisés, outils pour LLM et interface React. Le réentraînement continu et l’évaluation des prévisions permettent de mesurer la confiance du modèle dans le temps.

Comparatif d’IA — Analyseur de statistiques de basketball

Ouvrir l’application ↗ Voir le code source
DATE Avril 2026 TYPE Comparaison d’outils d’IA / Full-stack

Un benchmark contrôlé de six outils de programmation par IA—BMAD v4, Traycer, Amp, Superpowers, Ralph et BMAD v6—à partir d’une même spécification Flask de statistiques de basketball. Une grille normalisée évalue l’exactitude, la qualité du code et l’expérience développeur, tandis qu’un sélecteur interactif présente chaque implémentation.

Points techniques :

  • Six applications Flask développées indépendamment et exécutées sur des ports isolés (8080–8085)
  • Grille normalisée évaluant l’exactitude, la qualité du code et l’UX
  • Tableau de bord interactif avec sélecteur d’iframes pour une comparaison côte à côte
  • Pipeline automatisé de prérendu statique déployant toutes les applications sur GitHub Pages
  • Conception adaptative du sélecteur et de toutes les pages d’outils
  • Flux CI/CD avec GitHub Actions pour le déploiement continu

Technologies utilisées :

Python Flask pandas HTML/CSS JavaScript GitHub Pages GitHub Actions

Résultat :

Superpowers a obtenu la meilleure note (35/40), tandis que Traycer et Amp sont à égalité avec 32. BMAD v4 et BMAD v6 ont obtenu 30, tandis que Ralph n’a pas produit d’application fonctionnelle (8/40). Le sélecteur en direct permet d’explorer instantanément le résultat de chaque outil et offre un comparatif transparent et reproductible pour évaluer les flux de développement assistés par IA.

Analyse du risque de maladie cardiaque avec R

Voir le code source
DATE Automne 2024 TYPE Science des données et analyse statistique

Une analyse reproductible sous R des facteurs de risque cardiovasculaire à partir de 1 025 dossiers du jeu UCI Heart Disease. Le flux combine analyse exploratoire, tests d’hypothèses et régression logistique pour évaluer les indicateurs cliniques associés au diagnostic.

Points techniques :

  • Pipeline complet de prétraitement et de nettoyage de 14 variables cliniques
  • Analyse exploratoire avec visualisations professionnelles dans ggplot2
  • Modèle de régression logistique atteignant 84,8 % de précision et une AUC de 0,93
  • Analyse de corrélation identifiant les principaux facteurs de risque (type de douleur thoracique, dépression ST, nombre de vaisseaux)
  • Tests de significativité statistique (tests t et du khi carré) des tendances démographiques
  • Rapport R Markdown complet avec analyse reproductible

Technologies utilisées :

R R Studio ggplot2 dplyr caret corrplot R Markdown

Résultat :

Le modèle logistique atteint 84,8 % de précision et une AUC de 0,93. Les tests statistiques identifient le type de douleur thoracique, la fréquence cardiaque maximale, la dépression ST et le nombre de vaisseaux comme signaux diagnostiques importants, documentés dans R Markdown.
