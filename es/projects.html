FootballMind

Abrir aplicación ↗ Ver código fuente
FECHA 2026 TIPO Análisis predictivo / IA

Una plataforma conversacional de inteligencia futbolística para ocho competiciones importantes. Pregunta por un partido en lenguaje natural y recibe probabilidades de victoria, empate y derrota basadas en datos, junto con goles esperados, estado de forma, historial de enfrentamientos, alineaciones previstas y un análisis opcional redactado por IA.

Qué lo hace diferente:

  • Motor híbrido Elo + Dixon–Coles ajustado mediante backtesting progresivo con Ranked Probability Score
  • Partidos en vivo, tablas, cuadros de torneos, datos de jugadores, onces previstos y calibración de confianza
  • Seguimiento conversacional sensible a cada competición y comparaciones de jugadores en ocho competiciones
  • Ingesta, enriquecimiento, reentrenamiento del modelo y evaluación en días de partido automatizados mediante GitHub Actions
  • Una capa de servicios compartida disponible mediante una aplicación web React, una API REST y más de 13 herramientas MCP

Desarrollado con:

Python React Vite Flask PostgreSQL Elo Dixon–Coles MCP

Resultado:

Entregué un sistema de producción que abarca modelado estadístico, ingeniería de datos, herramientas para LLM y diseño de producto frontend. El modelo se reentrena y evalúa continuamente sus pronósticos para que su nivel de confianza pueda medirse, no solo afirmarse.

Análisis del riesgo de cardiopatía en R

Ver código fuente
FECHA Otoño de 2024 TIPO Ciencia de datos y análisis estadístico

Proyecto integral de análisis estadístico de factores de riesgo cardiovascular con el conjunto de datos UCI Heart Disease (1.025 registros de pacientes). Desarrollé modelos predictivos para identificar pacientes de alto riesgo y analicé indicadores clínicos clave asociados con el diagnóstico de cardiopatías.

Características principales:

  • Canal completo de preprocesamiento y limpieza de datos para 14 variables clínicas
  • Análisis exploratorio con visualizaciones profesionales mediante ggplot2
  • Modelo de regresión logística con 84,8 % de precisión y una puntuación AUC de 0,93
  • Análisis de correlación que identifica factores de riesgo clave (tipo de dolor torácico, depresión ST y número de vasos)
  • Pruebas de significancia estadística (t de Student y chi-cuadrado) para patrones demográficos
  • Informe completo en R Markdown con análisis reproducible

Tecnologías utilizadas:

R R Studio ggplot2 dplyr caret corrplot R Markdown

Resultados y conclusiones:

Identifiqué que los hombres presentan una prevalencia de cardiopatía significativamente mayor que las mujeres y que el dolor torácico asintomático muestra la asociación más fuerte con la enfermedad. El modelo predictivo logró métricas sólidas (>80 % de precisión, AUC de 0,93), lo que demuestra su potencial para la evaluación de riesgo clínico. El análisis reveló que la frecuencia cardíaca máxima y la depresión ST son indicadores diagnósticos críticos. El proyecto demostró dominio del modelado estadístico, la visualización de datos y el análisis de datos médicos.

Script automatizado de organización de datos

FECHA Verano de 2024 TIPO Automatización de procesos - Proyecto de prácticas

Durante mis prácticas desarrollé un script inteligente de automatización en Python que transformó los flujos de organización de datos. El script extrae nombres de ubicaciones específicas, clasifica archivos adicionales según criterios de coincidencia y organiza todo sistemáticamente, ahorrando unas 2 semanas de trabajo manual por ciclo.

Características principales:

  • Extracción automática de nombres desde estructuras de directorios designadas
  • Algoritmo inteligente de coincidencia de patrones para identificar archivos relacionados
  • Análisis multifactorial de similitud (patrones de nombres, fechas y metadatos)
  • Procesamiento por lotes de cientos de archivos simultáneamente
  • Sistema integral de gestión de errores y registros
  • Comprobaciones para garantizar una clasificación precisa
  • Generación de informes CSV para auditoría y verificación

Tecnologías utilizadas:

Python 3 pandas os/pathlib Regular Expressions File I/O Error Handling

Impacto empresarial:

Reduje el tiempo de organización de datos de 2 semanas a unas 2 horas por ciclo, un ahorro del 98 %. Eliminé el error humano en la clasificación de archivos y mejoré la precisión de aproximadamente un 85 % a un 99,5 %. En el despliegue inicial se procesaron más de 1.000 archivos sin errores. El equipo adoptó el script como flujo estándar y sigue ahorrando más de 80 horas mensuales de trabajo manual. Recibí un reconocimiento del supervisor por la solución innovadora y las mejoras medibles de eficiencia. El proyecto demostró mi capacidad para identificar oportunidades de automatización y entregar soluciones listas para producción con gran valor empresarial.
