FootballMind

Abrir aplicación ↗ Ver código fuente
FECHA 2026 TIPO Análisis predictivo / IA

Una plataforma de análisis futbolístico para ocho competiciones principales. Las consultas en lenguaje natural devuelven probabilidades calibradas de victoria, empate y derrota, además de goles esperados, forma reciente, enfrentamientos directos, alineaciones previstas y análisis opcional generado por IA.

Aspectos técnicos:

  • Motor híbrido Elo + Dixon–Coles ajustado mediante backtesting progresivo con Ranked Probability Score
  • Partidos en vivo, tablas, cuadros de torneos, datos de jugadores, onces previstos y calibración de confianza
  • Seguimiento conversacional sensible a cada competición y comparaciones de jugadores en ocho competiciones
  • Ingesta, enriquecimiento, reentrenamiento del modelo y evaluación en días de partido automatizados mediante GitHub Actions
  • Una capa de servicios compartida disponible mediante una aplicación web React, una API REST y más de 13 herramientas MCP

Desarrollado con:

Python React Vite Flask PostgreSQL Elo Dixon–Coles MCP

Resultado:

Construí un sistema integral que combina modelado estadístico, canales de datos automatizados, herramientas para LLM y una interfaz React. El reentrenamiento continuo y la evaluación de pronósticos permiten medir la confianza del modelo a lo largo del tiempo.

Benchmark de IA — Analizador de estadísticas de baloncesto

Abrir aplicación ↗ Ver código fuente
FECHA Abril de 2026 TIPO Comparación de herramientas de IA / Full stack

Un benchmark controlado de seis herramientas de programación con IA—BMAD v4, Traycer, Amp, Superpowers, Ralph y BMAD v6—con la misma especificación Flask de estadísticas de baloncesto. Una rúbrica estandarizada evalúa corrección, calidad del código y experiencia de desarrollo; un selector interactivo muestra cada implementación para compararla.

Aspectos técnicos:

  • 6 aplicaciones Flask creadas de forma independiente y ejecutadas en puertos aislados (8080–8085)
  • Rúbrica estandarizada que abarca corrección, calidad del código y UX
  • Panel interactivo con iframes para comparaciones lado a lado
  • Canal automatizado de prerenderizado estático que despliega todas las aplicaciones en GitHub Pages
  • Diseño adaptable a móviles en el selector y en todas las páginas de herramientas
  • Flujo de CI/CD mediante GitHub Actions para despliegue continuo

Tecnologías utilizadas:

Python Flask pandas HTML/CSS JavaScript GitHub Pages GitHub Actions

Resultado:

Superpowers obtuvo la puntuación más alta (35/40), seguido de Traycer y Amp, empatados con 32. BMAD v4 y BMAD v6 obtuvieron 30, mientras que Ralph no logró producir una aplicación funcional (8/40). El panel en vivo permite explorar al instante el resultado de cada herramienta y ofrece una referencia transparente y reproducible para evaluar flujos de desarrollo asistidos por IA.

Análisis del riesgo de cardiopatía en R

Ver código fuente
FECHA Otoño de 2024 TIPO Ciencia de datos y análisis estadístico

Un análisis reproducible en R de factores de riesgo cardiovascular con 1.025 registros del conjunto UCI Heart Disease. El flujo combina análisis exploratorio, pruebas de hipótesis y regresión logística para evaluar indicadores clínicos asociados con el diagnóstico.

Aspectos técnicos:

  • Canal completo de preprocesamiento y limpieza de datos para 14 variables clínicas
  • Análisis exploratorio con visualizaciones profesionales mediante ggplot2
  • Modelo de regresión logística con 84,8 % de precisión y una puntuación AUC de 0,93
  • Análisis de correlación que identifica factores de riesgo clave (tipo de dolor torácico, depresión ST y número de vasos)
  • Pruebas de significancia estadística (t de Student y chi-cuadrado) para patrones demográficos
  • Informe completo en R Markdown con análisis reproducible

Tecnologías utilizadas:

R R Studio ggplot2 dplyr caret corrplot R Markdown

Resultado:

El modelo logístico alcanzó un 84,8 % de precisión y un AUC de 0,93. Las pruebas estadísticas identificaron el tipo de dolor torácico, la frecuencia cardíaca máxima, la depresión ST y el número de vasos como señales diagnósticas relevantes, con resultados documentados en R Markdown.

Diagrama de flujo del script de Python

Script automatizado de organización de datos

FECHA Verano de 2024 TIPO Automatización de procesos - Proyecto de prácticas

Un canal de procesamiento de archivos en Python desarrollado durante unas prácticas. Extrae identificadores de estructuras de directorios, relaciona archivos mediante nombres, fechas y metadatos, valida las clasificaciones y genera un informe CSV auditable.

Aspectos técnicos:

  • Extracción automática de nombres desde estructuras de directorios designadas
  • Algoritmo inteligente de coincidencia de patrones para identificar archivos relacionados
  • Análisis multifactorial de similitud (patrones de nombres, fechas y metadatos)
  • Procesamiento por lotes de cientos de archivos simultáneamente
  • Sistema integral de gestión de errores y registros
  • Comprobaciones para garantizar una clasificación precisa
  • Generación de informes CSV para auditoría y verificación

Tecnologías utilizadas:

Python 3 pandas os/pathlib Regular Expressions File I/O Error Handling

Impacto operativo:

Reduje cada ciclo de procesamiento de unas dos semanas a aproximadamente dos horas. El despliegue inicial clasificó más de 1.000 archivos sin errores, elevó la precisión reportada de cerca del 85 % al 99,5 % y se convirtió en el flujo estándar del equipo.
